# Inventory Manager / 楼台库存助手

## Quick Start / 快速开始
Just ask your AI assistant: / 直接告诉 AI 助手：
- "Add 10 laptops to office inventory" (在办公室库存中增加10台笔记本)
- "List all items in my stock" (列出所有库存物品)
- "Remove 2 coffee beans from pantry" (从食品柜中核减2袋咖啡豆)

## Commands / 常用功能

### add
Add or update item quantity.
```bash
bash scripts/script.sh add "Macbook Pro" 5
```

### list
Show all current inventory.
```bash
bash scripts/script.sh list
```
